# MyAcademicGuide

Consolidated repository for the MyAcademicGuide platform, merged from four
previously separate repos (full commit history preserved via `git subtree`):

- `student/` — student-facing frontend (was `MAG_Student_Side`)
- `advisor/` — advisor-facing frontend (was `MAG_Advisor_Side`)
- `it/` — IT personnel frontend (was `MAG_IT_Side`)
- `backend/` — backend API (was `MAG_Backend_fork`, a fork of `Doaa2024/MAG_Backend`)

The three frontends are React + TypeScript apps.
