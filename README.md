# MyAcademicGuide

Consolidated repository for the MyAcademicGuide platform, merged from three
previously separate frontend repos (full commit history preserved via
`git subtree`):

- `student/` — student-facing frontend (was `MAG_Student_Side`)
- `advisor/` — advisor-facing frontend (was `MAG_Advisor_Side`)
- `it/` — IT personnel frontend (was `MAG_IT_Side`)

All three are React + TypeScript apps.
